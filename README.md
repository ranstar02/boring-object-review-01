One funny, true one-line review of the most boring everyday object in the
kitchen: the bag of plastic bags stuffed under the sink. Every household has
one, it never gets used, and it somehow outlives everything around it.

> The bag of plastic bags under my sink has outlived three kitchens, two relationships and one flood, and not one of them has ever been used.

The program writes exactly that line (139 characters, one line, no trailing
newline) to `entry.txt`.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`. To write elsewhere, set
`MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
